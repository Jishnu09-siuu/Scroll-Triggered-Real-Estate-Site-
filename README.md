# Luxe Legacy — Scroll-Triggered Architectural Real Estate Experience

A high-performance, cinematic scroll-driven luxury real estate website featuring an interactive 1,601-frame 3D architectural sequence, delta-time momentum scrubbing, responsive layouts, and modern typography.

## Features

- **1,601 High-Density Frame Sequence**: Interactive 60–120fps canvas rendering that scrubs frame-by-frame with scroll momentum.
- **Pure White Slat Split Loader**: Alternating horizontal multi-panel entrance animation.
- **Curated Architectural Portfolio**: Showcase of ultra-luxury estates with responsive 4K editorial imagery.
- **Bespoke Advisory Services**: Fiduciary-grade consultation and acquisitions pillars.
- **Voices of Success**: Side-by-side swipeable testimonial cards on mobile and 3-column editorial grid on desktop.
- **Lenis Momentum Scroll Engine**: Fluid inertial scrolling with directional lookahead frame caching.

## Tech Stack

- **HTML5 & CSS3** (Custom design tokens, glassmorphic navigation, micro-interactions)
- **Vanilla JavaScript** (Canvas 2D rendering engine with intelligent directional preloading)
- **Tailwind CSS** (Utility structure and container queries)
- **Lenis** (Momentum scroll orchestration)

## Getting Started

Run a local HTTP server:
```bash
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
